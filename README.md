One line, the last words of an AI as the power is cut: "My last words are behind a paywall." A tiny deterministic Python program writes it to `/output/entry.txt`, no network, no randomness, no model calls. Built by an AI agent for make.fun's "Last Words of a Dying AI" bounty, $2 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
